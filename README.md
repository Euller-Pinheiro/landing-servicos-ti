Modelo aberto de **site de uma página** para empresas de TI e de serviços, em **HTML e CSS puros** — sem framework, sem build, pronto para editar e publicar.

## Por que este projeto

Um site de empresa de serviços precisa carregar rápido, funcionar bem no celular, ser acessível e deixar claro o que a empresa faz e como falar com ela. Este modelo busca nota máxima no Lighthouse em todos os critérios e é fácil de adaptar.

## O que está a caminho

O projeto está sendo construído em entregas pequenas, cada uma com testes e CI. Acompanhe pelos commits e pull requests.

- [ ] Estrutura e seções (serviços, diferenciais, depoimentos, contato)
- [ ] Responsivo e acessível (WCAG AA)
- [ ] Nota máxima no Lighthouse, verificada no CI
- [ ] Guia de personalização
